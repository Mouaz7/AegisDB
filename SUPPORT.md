# Support for AegisDB

Thank you for exploring AegisDB! Here are the recommended ways to find answers, report issues, or get assistance.

---

## Getting Help

- **Documentation**: Check out the comprehensive architectural guides and ADRs in [`docs/`](docs/) and the operational instructions in [`README.md`](README.md).
- **GitHub Discussions**: For conceptual questions, distributed systems design inquiries, or research feedback, please visit our GitHub Discussions tab.
- **Issue Tracker**: For reporting bugs or requesting new features, please open an issue using the provided templates:
  - [Bug Report](.github/ISSUE_TEMPLATE/bug_report.yml)
  - [Feature Request](.github/ISSUE_TEMPLATE/feature_request.yml)

---

## Security Vulnerabilities

If you discover a security vulnerability or potential exploit, please **do not** file a public issue. Review our [Security Policy](SECURITY.md) to report it privately and securely.
