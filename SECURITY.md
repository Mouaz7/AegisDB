# Security Policy

## Supported Versions

Currently, AegisDB supports the following versions for security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability in AegisDB, please **do not** open a public issue. Instead, report it privately via GitHub Security Advisories or email the maintainers directly.

We will try to respond to all vulnerability reports within 48 hours and coordinate a patch release.
